# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique code and not people, and
no harassment of any kind. Maintainers may remove comments, commits, or
contributors that break this.

Report problems privately to the maintainer, [@Ahmed8881](https://github.com/Ahmed8881),
through a GitHub private vulnerability report or the contact on their profile.
