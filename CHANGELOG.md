# Changelog

## 0.1.0 - 2026-11-08

### Added
- `SKILL.md` workflow: read existing patterns, list states, build each, attack with hostile data, scan.
- References: `states.md` (pattern per state), `copy.md` (wording), `hostile-data.md` (variants).
- `scripts/scan.mjs`: nine heuristic rules for missing states in JSX/TSX/Vue/Svelte.
- `scripts/fixtures.mjs`: 14 hostile data variants from one sample record.
- `scripts/matrix.mjs`: side-by-side render of a component in every variant, crashes highlighted.
- Evals, known-good/bad fixtures, structure lint, and CI.
